# Project Swabun | Enactus Ramjas

A React + Vite + Tailwind CSS site showcasing Project Swabun (Unnati, Aaroha and Sehar).

## Run locally

```
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a Git repository and import it in Vercel (or run `vercel` from this folder).
2. Vercel detects Vite automatically (settings are in `vercel.json`): build command `npm run build`, output directory `dist`.
3. No environment variables are required.
